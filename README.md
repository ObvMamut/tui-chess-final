## TUI Game of Chess

### Functionalities

This Game allows for every Chess functionnality except for :
- playing againts an AI (Stockfish)
- en-passant for pawns

These functionalities are not yet implemented because I am lazy and not very motivated, I'm not sure if I intend on adding them in the future

### Installing & Running

1. copy the repo
2. compile (with cargo)
3. run in a terminal (like Alacritty)
